# 方案 A：项目阅读与讲解指南

本项目用 SPY 日频数据，检验五个技术特征能否通过 Ridge 回归改善择时。当前结论：**扣除交易成本后，策略没有优于买入持有；风险有所降低，但投入股市的时间也更少。** 不应把结果包装成成功策略。

## 先看什么

1. `README.md`：完整流程、运行命令与指标定义。
2. `output/pdf/Group_X_Report.pdf`：21 页英文报告，团队与贡献字段留空。
3. `output/tables/test_metrics.csv`：最终样本外指标。
4. `output/figures/01_wealth.png` 和 `04_costs.png`：主要结论。
5. `output/video/walkthrough_script.md`：20 个章节的英文视频讲稿。

## 讲清楚这六点

- **为什么选这些特征**：趋势可能延续，短期冲击可能反转，波动率描述风险状态；它们是待检验假设。
- **为什么用 Ridge**：五个特征之间相关，L2 收缩帮助稳定估计；模型简单、易复现。
- **怎样避免未来信息**：收盘出信号，次日开盘成交；标签是之后开盘到开盘的收益；训练只纳入结果已实现的标签；标准化只用训练窗口。
- **怎样选模型**：2019–2021 年验证期比较四个 alpha；按扣成本 Sharpe 选出 alpha=1；测试期不再选参。
- **怎样算钱**：显式处理分红资格，进出场都扣成本，基准也扣首次买入和最终卖出成本；现金与 Sharpe 无风险利率均假设为 0。
- **结果意味着什么**：2022–2025 年净 CAGR 6.54%、Sharpe 0.481，低于买入持有的 11.18%、0.670；最大回撤约 -22.20%，基准约 -26.28%。

## 容易被问到的问题

**预测 R² 为负，项目是不是失败？**

预测没有优于过去均值，经济表现也未确立净优势。这是有效的负结果。项目价值在于研究流程和诚实解释。

**为什么验证期很好，测试期下降？**

市场关系可能变化，验证选参本身存在乐观偏差；模型抓到的也可能只是噪声。不能凭该实验确定唯一原因。

**最大回撤更小，能否说策略更好？**

需要同时看收益、Sharpe 和仓位。策略只有约 69.36% 的持有区间投入股市，降低风险可能主要来自更低暴露。

**成本有多重要？**

Ridge 零成本 Sharpe 约 0.678，单边 5 bps 后约 0.481。总单边换手 246 次单位，明显高于基准的 2 次。

**测试期每月重新训练是不是泄漏？**

预先固定重训规则、只加入已经实现的结果是允许的滚动预测；根据测试收益再修改超参数或特征才破坏最终评估。

**复权价格会不会包含未来信息？**

特征使用比例和收益，之后统一乘到历史窗口上的复权因子会抵消，代码有相应测试。但数据商历史修订仍可能改变结果，因此记录输入哈希。
